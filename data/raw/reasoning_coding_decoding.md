# Logical Reasoning: Coding-Decoding

## Core Concept
Coding-Decoding tests pattern recognition between a word/number and its "coded" form. The
question always establishes a rule using one or more example pairs, and you must apply the
same rule to a new word or number.

## Common Coding Types
1. **Letter Shifting (Alphabet Coding)**: Each letter is shifted forward or backward by a
   fixed number of positions in the alphabet. Example: if CAT is coded as DBU, each letter
   has shifted forward by 1 (C→D, A→B, T→U).
2. **Number Coding**: Letters are replaced by their position numbers (A=1, B=2, ... Z=26) or
   by a reversed scheme (A=26, B=25, ... Z=1), sometimes combined with arithmetic operations.
3. **Substitution Coding**: A direct word-for-word or symbol-for-word substitution is given,
   and you must trace a chain of substitutions across multiple statements.
4. **Jumbling/Reversal Coding**: Letters within the word are reversed or rearranged according
   to a fixed pattern.

## Worked Example
If "MOUNTAIN" is coded as "NPVOUBJO," identify the rule.
Check each letter: M→N (+1), O→P (+1), U→V (+1), N→O (+1), T→U (+1), A→B (+1), I→J (+1),
N→O (+1).
Rule: every letter shifts forward by exactly 1 position in the alphabet.
So "VALLEY" would be coded as "WBMMFZ".

## Common Mistakes
1. Assuming the shift is the same in both directions without checking — always verify with
   at least two letters before generalizing the rule.
2. Forgetting to wrap around the alphabet (Z + 1 = A) when a shift pushes past Z.
3. In number-coding questions, missing an additional arithmetic step (e.g., add the position
   number, then reverse the digits) because the question tests a two-step rule, not a
   single-step one.
