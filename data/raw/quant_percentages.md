# Quantitative Aptitude: Percentages

## Core Concept
A percentage expresses a number as a fraction of 100. "x percent of y" is calculated as
(x/100) * y. Percentages are used across almost every quant topic — profit & loss, simple
and compound interest, data interpretation, and mixtures — so fluency here saves time on
every other chapter.

## Percentage Change
If a quantity changes from an initial value V1 to a final value V2, the percentage change is:
    Percentage Change = ((V2 - V1) / V1) * 100
A positive result means an increase; a negative result means a decrease.

## Successive Percentage Change
When a value undergoes two successive percentage changes of a% and b%, the net percentage
change is NOT simply (a + b)%. The correct formula is:
    Net Change % = a + b + (a*b)/100
This adjustment term (a*b)/100 is the most common source of errors in exams — students often
forget it when one change is a decrease (in which case the corresponding value is taken as
negative).

## Common Shortcut: Fraction Equivalents
Memorizing fraction-to-percentage equivalents speeds up calculation significantly:
- 1/2 = 50%, 1/4 = 25%, 1/8 = 12.5%
- 1/3 = 33.33%, 1/6 = 16.67%, 1/7 ≈ 14.28%
- 1/9 = 11.11%, 1/11 ≈ 9.09%, 1/12 ≈ 8.33%

## Worked Example
A shopkeeper increases the price of an item by 20% and then, during a sale, decreases the new
price by 10%. What is the net percentage change from the original price?
Using the successive change formula: a = 20, b = -10
Net Change % = 20 + (-10) + (20 * -10)/100 = 20 - 10 - 2 = 8%
So the final price is 8% higher than the original price, not 10% higher as a naive
subtraction (20 - 10) might suggest.

## Common Mistakes
1. Forgetting the successive-change adjustment term when combining an increase and a decrease.
2. Confusing "percentage of" with "percentage point" difference, especially in DI sets.
3. Not converting a percentage decrease to a negative value before applying formulas.
